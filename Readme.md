# Olist E-Commerce Sales Analysis

## Project Overview
End-to-end data analysis of 96,000+ delivered orders from Olist, 
Brazil's largest e-commerce marketplace. Built using Python for 
data cleaning and Power BI for interactive dashboard.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn, Plotly)
- Power BI Desktop
- Jupyter Notebook

## Dataset
- Source: Kaggle — Brazilian E-Commerce Public Dataset by Olist
- Size: 110,168 rows across 5 merged tables

## Key Insights
1. Total revenue of R$15.4M across 96,453 delivered orders
2. Health & Beauty is the top revenue category at R$1.4M
3. São Paulo (SP) accounts for 37% of total revenue
4. Average delivery time is 12 days with a 6.59% late order rate
5. 75% of customers pay by credit card

## Dashboard Visuals
- KPI Cards: Total Revenue, Orders, Avg Delivery Days, Late Order Rate
- Monthly Revenue Trend (line chart)
- Top 10 Categories by Revenue (bar chart)
- Revenue by State (column chart)
- Avg Delivery Days by Category (column chart)
